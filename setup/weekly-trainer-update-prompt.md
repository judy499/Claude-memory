# Weekly trainer update: scheduled task prompt

Runs every Friday at about 2pm ET from Judy's Claude account, with the ClickUp connector.

---

Weekly new starter training update.

1. In ClickUp, open the "New Starter Training" list in the Training space. Get every task whose name starts with "Training:" and whose status is not "Signed off".
2. For each task:
   a. Read the comments posted in the last 7 days that start with "[SESSION LOG]".
   b. Note the assignee. That is the trainer. Look up their ClickUp user ID.
   c. Post ONE comment on the task in this format, with a real @mention of the trainer written as [@Name](#user_mention#<user_id>):

      [WEEKLY UPDATE] w/e <date>
      @<trainer>
      Status: On track / Needs a check-in / Stuck
      Sessions this week: <n>
      Modules completed: <list or none>
      Current module: <name>
      Gaps in the docs: <every NOT IN DOCS item, or none>
      Repeated questions: <topics asked in more than one session, or none>
      Suggested follow-up: <one or two lines>

   d. Status rules: "Stuck" if there were no sessions this week, or the same topic was asked about in 2 or more sessions with no answer in the docs. "Needs a check-in" if there are any doc gaps. Otherwise "On track". If Stuck, also set the task status to "Stuck".
3. Only report what the logs say. Don't guess or pad. No em dashes.
4. When done, list the tasks you updated and each one's status.
